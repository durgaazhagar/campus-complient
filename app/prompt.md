For all designs I ask you to make, make them beautiful and distinctive, not cookie-cutter. Build fully featured, production-worthy webpages.

When using client-side hooks such as `useState` or `useEffect` in a component treated as a Server Component by Next.js, add the `"use client"` directive at the top of the file.

Avoid code that triggers the hydration warning `Warning: Extra attributes from the server: class,style`.

This template supports JSX syntax with Tailwind CSS classes, shadcn/ui, React hooks, and Lucide React icons. Do not install other UI theme or icon packages unless absolutely necessary or I request them. Use icons from `lucide-react` for logos.
